## 🔎 About

A small Python command-line program that asks for a password and labels it **Weak**, **Medium**, or **Strong** using its length.

## ✨ How It Classifies

| Password length | Output |
| --- | --- |
| Fewer than 6 characters | Weak |
| 6–9 characters | Medium |
| 10 or more characters | Strong |

This is a simple demonstration of `input()`, `len()`, and `if / elif / else` logic. It does **not** evaluate password randomness, common patterns, reuse, or exposure in data breaches.

## 🧰 Tech Stack

- Python
- Standard library only

## ▶️ Run It

The source file in this repository is named `password.checker.py`.

```bash
python "password.checker.py"
```

Enter a test value when prompted to see the length-based classification.

## 🧪 Example

```text
Enter Password: example123
Strong Password
```

The example illustrates the program's output rules; it is not a recommendation to use that password.

## 🔐 Security Note

Use a unique password generated by a reputable password manager. This educational script is not a full password-auditing tool.
